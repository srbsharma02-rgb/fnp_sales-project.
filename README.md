# 📊 FNP (Ferns N Petals) Sales Analysis Dashboard

## 📌 Project Overview
An interactive **Microsoft Excel Sales Analysis Dashboard** built to evaluate order performance, revenue distribution, and customer purchasing patterns for **FNP (Ferns N Petals)**. The dashboard transforms raw transactional data into actionable business insights using Pivot Tables, Pivot Charts, and interactive Slicers.

## 🎯 Key Performance Indicators (KPIs)
- **Total Orders:** 1,000
- **Total Revenue:** ₹35,20,984.00
- **Average Customer Spend:** ₹3,520.98
- **Average Order-Delivery Time:** 5.50

## 📈 Visualizations Included
1. **Revenue by Occasions:** Compares sales across major events (Anniversary, Raksha Bandhan, Holi, Birthday, Diwali, Valentine's Day).
2. **Revenue by Category:** Highlights top-performing product types (Colors, Soft Toys, Sweets, Plants, Cake, etc.).
3. **Revenue Trend (Weekly/Hourly):** Tracks revenue fluctuations across days of the week.
4. **Revenue by Months:** Displays seasonal peaks and monthly sales trends.
5. **Top 5 Products by Revenue:** Identifies the highest revenue-generating items.
6. **Top 10 Cities by Order:** Shows geographic demand across cities like Imphal, Dhanbad, etc.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel**
- **Data Cleaning & Formatting**
- **Pivot Tables & Pivot Charts**
- **Interactive Slicers & Timelines** (Order Date, Delivery Date, Occasion)

## 💡 Key Takeaways
- **Anniversary** and **Raksha Bandhan** are the primary revenue drivers among all occasions.
- **Colors**, **Soft Toys**, and **Sweets** contribute significantly to category-wise revenue.
- Sales peak noticeably on **Tuesdays** and **Sundays**.
